

[QA-E2E] Implementação da Suíte de Automação de Testes E2E e API com Playwright



Informações principais
Descrição

Como Analista de QA do projeto Ultra Exercises,
Quero implementar uma estrutura automatizada de testes End-to-End (E2E) e de API utilizando o Playwright,
Para garantir a regressão automática das principais jornadas do usuário, validar contratos de API em ciclos de entrega contínua (CI/CD) e reduzir o tempo de feedback de qualidade.

Objetivos de Qualidade & Benefícios:
🎯 Cobertura Regressiva: Garantir que as funcionalidades críticas (Autenticação, Gestão de Treinos e Progresso) não quebrem a cada novo deploy.

⚡ Execução Ágil: Testar a comunicação entre o Frontend (React) e o Backend (Spring Boot) em navegadores reais (Chromium/Firefox/WebKit).

📊 Rastreabilidade Visual: Gerar relatórios automatizados com capturas de tela e vídeos de execução em caso de falhas.
